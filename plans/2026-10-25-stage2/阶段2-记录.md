## 实现内容

- `RealtimeOpenRequest.tools`：校验 function schema、唯一工具名与目录总字节；打开时按协商限额复查。
- Qwen 工具目录下发、回显一致性检查、缺失时 `unsupported`，`SessionReady.tools_acknowledged`。
- `ToolDispatcher`：只处理完整 done 事件，独立异步任务执行，结果回执后续答；非法 JSON、重复键、非有限数字、schema 不符、未知工具、参数超限直接回工具错误且不暴露给手工执行。
- generation：拒绝旧调用、旧结果、旧队列音频及本地输出；同一外部会话跨重连去重，不误伤不同会话中相同的 call_id。
- 上下文：`append_message`、`update_instructions`、`out_of_band_response`；可选续答等待回执，拒绝映射 `unsupported` 并记无内容诊断，模糊超时终结会话；Qwen 带外生成直接拒绝。
- OpenAI：保留离线边界和全部既有 conformance fixture；补消息、指令更新及 `response.create(instructions)`、`conversation: "none"` 编码。
- 本地播放：可选 `played_audio_ms`，位置单调且不超过已确认帧时长；不可变快照包含发送字节、发送时长与播放位置，老 ACK 格式继续可用。
- Harness 改为精确 `==0.13.0.dev20260925+opt.216`，Memory extra 不变。实际 opt.216 schema 与来源尚无证据，BOM 暂存 `execution_schema: null`、`pending-offline-wheel`；BOM 与正式构建入口均明确拒绝未核验状态。

schema 使用文档明确列出的受限 JSON Schema 子集，最大嵌套 32 层；其他关键词（含远程引用）明确拒绝，没有静默忽略。
